Measure twice, order the right furnace filter

Quick take (pin): Before furnace season: pull the old filter, order THAT size, write the change date on the new one.

A clogged filter is a quiet way to burn more heat, trip high-limits, and start “the house feels dusty” complaints. Before furnace season in the BC Interior:

  1. Pull the old filter and read the size on the frame — order that nominal size (actual size is usually a hair smaller).
  2. Match MERV to the system — higher isn’t always better on older blowers; when unsure, stick to what the furnace manual allows.
  3. Change on a schedule (often ~3 months for 1″ pleated) and write the date on the new frame.
  4. Keep a spare on site so you’re not hunting during a cold snap.
